# Cross-agent development benchmark

Six development tasks, one attempt each by Claude Sonnet and Codex, graded by the TrainDoctor verifier. Read `BENCHMARK_REPORT.md` for the result and `RESULTS.md` for the setup and table; `results/` holds the 24 scored rows (agent x task).

The task prompts, raw agent answers, replay outcomes, run metadata and the harness script were archived privately and are not published, so the runs cannot be re-executed from this repository. `SHA256SUMS` covers the files that remain; `RESULTS.md` differs from its recorded hash.
