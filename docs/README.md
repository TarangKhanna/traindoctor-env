# Documentation

Maintained guides for TrainDoctor. Raw results, frozen protocols and archived development notes live under [`../evidence/`](../evidence/); evaluation and audit experiments live under [`../experiments/`](../experiments/).

## Reading paths

- **5 minutes:** the top-level [`README`](../README.md), then the sealed test report ([`TEST_REPORT.md`](../evidence/results/TEST_REPORT.md)) and the red-team table ([`REDTEAM_TABLE.md`](../evidence/results/REDTEAM_TABLE.md)).
- **How it works:** [`ARCHITECTURE.md`](../ARCHITECTURE.md), [`VERIFICATION.md`](VERIFICATION.md), [`TASKS.md`](TASKS.md), [`DESIGN_NOTES.md`](DESIGN_NOTES.md).
- **Reproduce something:** [`QUICKSTART.md`](QUICKSTART.md) (local, no account), [`TESTING.md`](TESTING.md), and the [release manifest](../evidence/RELEASE_MANIFEST.md) (every headline number mapped to its file and command).
- **Build on it:** [`EXTENDING.md`](EXTENDING.md).
