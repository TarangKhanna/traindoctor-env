# Documentation

Guides for TrainDoctor. Raw results and frozen protocols are under [`../evidence/`](../evidence/); evaluation and audit experiments are under [`../experiments/`](../experiments/).

## Reading paths

- **5 minutes:** the top-level [`README`](../README.md), then the sealed test report ([`TEST_REPORT.md`](../evidence/results/TEST_REPORT.md)) and the red-team table ([`REDTEAM_TABLE.md`](../evidence/results/REDTEAM_TABLE.md)).
- **How it works:** [`ARCHITECTURE.md`](../ARCHITECTURE.md), [`VERIFICATION.md`](VERIFICATION.md), [`TASKS.md`](TASKS.md).
- **Reproduce something:** [`QUICKSTART.md`](QUICKSTART.md) (local, no account), [`TESTING.md`](TESTING.md), and the [evidence index](../evidence/README.md) (every headline number mapped to its file and recompute command).
- **Build on it:** [`EXTENDING.md`](EXTENDING.md).
