# Docs: start here

Plain-language map of everything under `docs/`. Evidence files are hash-checked (`results/SHA256SUMS`) and left exactly where they were.

## Reading paths

- **5 minutes:** the top-level [`README`](../README.md), then [`results/TEST_REPORT.md`](results/TEST_REPORT.md) (the sealed test) and [`REDTEAM_TABLE.md`](REDTEAM_TABLE.md) (every fake repair and how it was rejected).
- **Understand how it works:** [`../ARCHITECTURE.md`](../ARCHITECTURE.md), [`VERIFICATION.md`](VERIFICATION.md), [`TASKS.md`](TASKS.md), then [`DESIGN_NOTES.md`](DESIGN_NOTES.md).
- **Reproduce something:** [`QUICKSTART.md`](QUICKSTART.md) (local, no account), [`TESTING.md`](TESTING.md) (what passes and what needs an unrestricted machine), [`RELEASE_MANIFEST.md`](RELEASE_MANIFEST.md) (every headline number mapped to its file and command).
- **Build on it:** [`EXTENDING.md`](EXTENDING.md) (add a task), [`A2V2_SCENARIO.md`](A2V2_SCENARIO.md) (a harder scenario variant).
