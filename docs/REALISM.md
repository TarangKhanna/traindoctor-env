## Honest limitations

1. Evidence shows each failure class occurs at scale; it does not show our toy reproductions have the same symptom statistics, only the same causal shape.
2. Gloo on CPU removes GPU asynchrony, NCCL watchdog behavior, and hardware-fault signatures; hardware faults are authored telemetry, not detections.
3. Headline fleet figures (Llama 3, FLARE, Meta) are about frequencies on their clusters and do not set our fault sampling rates; our mix is a design choice.
4. L3 Table 5 printed percentages do not equal count/419 for some rows (e.g. 148/419 is about 35%); quoted as printed. FR Fig. 3 numbers are in an image that was not read.
5. Several labels (NONIDEMPOTENT_RESUBMIT, CKPT_VERSION_MISMATCH, OOM_AFTER_CONFIG_CHANGE) rest on weak indirect evidence.
